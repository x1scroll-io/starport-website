BEFORE YOU DEPART

A little clarity.

Can I download Starport today?

Yes. Experienced users can download the live developer beta below and load it unpacked in desktop Chrome. Mainnet transactions use real funds. The Chrome Web Store listing is coming soon (planned; not yet published or approved). iOS and Android are planned.

Does every network support every feature?

No. Holding assets, connecting to an app, signing transactions, and in-app swaps are different capabilities. Availability varies by network and route. A custom RPC does not automatically enable swaps or token-price data.

Do I have to manage the bridge myself?

Starport brings supported routes and their progress into the wallet. Networks still need time to confirm transactions, and some routes may need another approval or a recovery step. The wallet should tell you when action is required.

Can I connect to my favorite apps?

Connection depends on the app’s wallet discovery and the network it uses. Starport’s browser extension is being tested with compatible apps. Some apps need to add Starport to their wallet picker.

Is this website connected to my wallet?

No. The preview uses sample data and cannot sign or send transactions. It does not ask for your seed phrase, private key, or wallet connection.

Install the developer beta
  1. Download and extract the ZIP into a permanent folder.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Choose Load unpacked and select the package’s extension folder containing manifest.json.
  4. Pin Starport, open it, and create a separate beta wallet. Back up your recovery information privately.

This unpacked build requires manual updates. Finish pending approvals and back up recovery information before updating. Do not uninstall or clear storage to update.
