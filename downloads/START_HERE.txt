INSTALL IN DESKTOP CHROME
1. Extract this ZIP into a permanent folder.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Click Load unpacked and select the extracted folder (it contains manifest.json).
5. Pin Starport from Chrome's Extensions menu and open it.
6. Create a separate beta wallet and securely record its recovery information. Never send secrets to support.
Official Chrome guide: https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked
